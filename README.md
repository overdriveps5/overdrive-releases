# Overdrive releases

Builds of [Overdrive](https://github.com/overdriveps5/game-store), a game store for jailbroken PS5s.

## Install

Download the latest `Overdrive-PPSA99058.exfat.zip`:
https://github.com/overdriveps5/overdrive-releases/releases/latest/download/Overdrive-PPSA99058.exfat.zip

Close Overdrive, unzip it and copy the `.exfat` over the old one. The app updates itself from this repository after that.

Source code: [game-store](https://github.com/overdriveps5/game-store) · [ps5-react](https://github.com/overdriveps5/ps5-react)
